## Console e Como Declarar Variáveis

### Variável armazena um valor em memória.

let - É uma variável em que você pode alterar o valor a qualquer momento.

const - É uma variável que NÃO PODE mudar o valor depois de declarado.

```js
/* Variável que pode mudar o valor*/
let variavel1 = 78;

/* Variável que NÃO PODE mudar o valor*/
const variavel2 = 3;

console.log(variavel1)
console.log(variavel2)

/* Mudar o valor da variável1 de 78 para 0 */
variavel1 = 0;

/* Concatenar um texto com a variável*/
console.log(` O resultado atual da variável 1 é: ` + variavel1)

/* Operações matemáticas */
console.log(variavel1 + variavel2)
console.log(variavel1 - variavel2)
console.log(variavel1 * variavel2)
console.log(variavel1 / variavel2)

/* Mudar o valor da variável1 de 0 para um número com decimal */
variavel1 = 987.97;

/* Concatenar um texto com a variável*/
console.log(` O resultado atual da variável 1 é: ` + variavel1)

/* Operações matemáticas */
console.log(variavel1 + variavel2)
console.log(variavel1 - variavel2)
console.log(variavel1 * variavel2)
console.log(variavel1 / variavel2)

```
